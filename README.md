# 📚 Library Management System (LMS) in C++

A console‑based **Library Management System** built using **C++**.  
This project helps manage books and student records efficiently — allowing you to create, modify, delete, issue, and deposit books.

---

## 🧠 Features
- Add, modify, and delete **book records**
- Add, modify, and delete **student records**
- Issue and deposit books with fine calculation
- Display all books and students
- Simple text‑based interface using `iostream`, `fstream`, and `conio.h`

---

## 🛠️ Technologies Used
- C++ (Object‑Oriented Programming)
- File Handling (`fstream`)
- Console I/O (`iostream`, `conio.h`, `iomanip.h`)
- Classes and Objects

---
